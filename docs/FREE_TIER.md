# حدود الخدمات المجانية

> تاريخ المراجعة: **2026-09-25**. الأرقام تتغير — راجع الروابط الرسمية قبل الاعتماد. لا نعد بتشغيل مجاني غير محدود.
> مصادر الأرقام: نتائج بحث عن الصفحات الرسمية (الوصول المباشر لـ developers.cloudflare.com كان محجوبًا في بيئة البناء). البنود المعلّمة 🔎 من معرفة سابقة ولم تُطابَق مع صفحة رسمية حديثة.

## Cloudflare Workers (Free) — [الأسعار](https://developers.cloudflare.com/workers/platform/pricing/) · [الحدود](https://developers.cloudflare.com/workers/platform/limits/)

| البند | الحد | استهلاك HSN AutoReply |
|---|---|---|
| الطلبات | 100,000 / يوم | Webhooks + لوحة التحكم + Cron (1,440 تشغيل/يوم) |
| CPU | 10ms لكل استدعاء | المعالجة I/O في الغالب (انتظار الشبكة لا يُحسب). التحقق من كلمة المرور بـ PBKDF2 هو الأثقل؛ إن ظهر خطأ «Exceeded CPU» عند الدخول خفّض `PBKDF2_ITERATIONS` (مع بقاء الـ pepper السري) |
| الطلبات الخارجية | 50 لكل استدعاء (1000 لخدمات Cloudflare) | الطابور يتوقف عند 45 طلبًا خارجيًا في الدورة ويكمل في الدقيقة التالية |
| Cron Triggers | 🔎 5 لكل حساب | نستخدم 2 |
| حجم الـ Worker | ضمن الحد (≈175 KiB مضغوط) | |

عند تجاوز حد الطلبات اليومي تُرفض الطلبات (Meta تعيد إرسال الـ Webhooks لاحقًا لفترة محدودة) — لا توجد فوترة تلقائية على الخطة المجانية ما لم تُرقِّ بنفسك.

## Cloudflare D1 (Free) — [الأسعار](https://developers.cloudflare.com/d1/platform/pricing/)

| البند | الحد 🔎 |
|---|---|
| صفوف مقروءة | 5 ملايين / يوم |
| صفوف مكتوبة | 100,000 / يوم |
| التخزين | 5 GB |

الاستعلامات الدورية كلها مفهرسة (`action_jobs_due`, `flows_open_expires`). تقدير تقريبي: كل تعليق مطابق ≈ 15–30 صف مكتوب؛ أي آلاف التعليقات يوميًا ضمن الحد. قلّل `retention_days` لتقليل التخزين.

## GitHub (مستودع خاص، خطة Free) — [فوترة Actions](https://docs.github.com/billing/managing-billing-for-github-actions/about-billing-for-github-actions)

| البند | الحد |
|---|---|
| دقائق Actions (Linux) | 2,000 / شهر |
| تخزين Artifacts/Packages | 500 MB |

- CI (اختبارات + بناء) ≈ 2–3 دقائق لكل دفع؛ بناء APK ≈ 8–15 دقيقة.
- الـ workflows لا تعمل على تغييرات التوثيق فقط، وبناء APK يعمل فقط عند وسم إصدار أو يدويًا.
- الـ artifacts تُحفظ 7 أيام فقط؛ ملفات الـ Release لا تُحسب ضمن حصة Artifacts 🔎.
- عند نفاد الدقائق تتوقف الـ workflows (لا فوترة ما لم تضع حد إنفاق أكبر من 0 — أبقه 0).

## Meta
- Instagram API نفسه لا يفرض رسومًا 🔎، لكن عليه حدود معدل (Rate limits / BUC). النظام يحترم `Retry-After` و`X-Business-Use-Case-Usage`.
- Business Verification وApp Review مجانيان لكن يتطلبان وقتًا ومستندات.

## تكلفة أداة البرمجة
تكلفة استخدام Claude Code (أو أي أداة برمجة) **منفصلة تمامًا** عن تشغيل التطبيق. التطبيق نفسه لا يستدعي أي API ذكاء اصطناعي.

## إذا احتجت الترقية لاحقًا
- البديل المجاني أولًا: خفض مدة الاحتفاظ، تقليل الحملات النشطة، أو زيادة الفاصل لكل مستخدم.
- Workers Paid يرفع CPU والطلبات؛ قرار الترقية لك وحدك — المشروع لا يفعّله.
